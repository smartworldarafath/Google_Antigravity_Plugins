# C/C++ Language Server (Clangd)

> Official Google Antigravity Language Server Plugin

## Overview
C/C++ language server (clangd) integration for Google Antigravity, providing AST diagnostics, code intelligence, and formatting.

## Supported File Extensions
`.c`, `.h`, `.cpp`, `.cc`, `.cxx`, `.hpp`, `.hxx`, `.C`, `.H`

## Installation Guide
macOS: `brew install llvm` | Linux: `sudo apt install clangd` | Windows: `winget install LLVM.LLVM`

## Features
- **Code Intelligence**: Type checking, jump to definition, reference tracing.
- **Diagnostics**: Real-time error reporting and warning analysis.
- **Strict Compliance**: 100% Google Antigravity Customization Specification compliant.
